MyHub 采集器 · 绿色版 {{VERSION}}
=====================================================

解压即用：自带 Python 运行时和全部依赖，不用装 Python、不用 pip、不用命令行。
要求：Windows 10/11 64 位；本机装了 Chrome 或 Edge（登录和抖音抓取要用浏览器）。

一、第一次使用
-----------------------------------------------------
1. 把压缩包解压到一个固定目录，例如 D:\MyHub-Collector
   （不要放在 C:\Program Files 这类需要管理员权限的目录里）
2. 双击 start.bat
   - 会自动打开 http://127.0.0.1:17865/
   - 在页面里点「登录」，依次登录 B站 / YouTube / 抖音（登录态保存在 data\credentials）
   - 之后在「动态采集」「定时任务」页里操作即可
3. 只关掉 start.bat 的黑窗口就等于停止服务；日志不会丢。

二、开机自动后台启动（推荐用页面开关，不用跑脚本）
-----------------------------------------------------
1. 双击 start.bat 打开门户
2. 在「概览」页找到「开机自动启动」卡片，把开关打开
   - 打开后：已注册到当前用户的开机自启，以后开机自动在后台跑，不弹窗口、不弹浏览器
   - 关闭后：自动取消，下次开机不再启动
   - 开关状态取自注册表，重装 / 换目录后建议重新看一眼这个开关

门户地址固定为 http://127.0.0.1:17865/（端口写死，书签和快捷方式不会失效）。
如果这个端口被别的程序占了、或者被系统临时保留，服务会直接启动失败并把原因写进
data\logs\myhub-collector.log，按日志里的提示换个端口即可。

备用方案（页面开关不可用时才需要）：双击 install-autostart.vbs 注册，
双击 uninstall-autostart.vbs 取消。
想停掉正在后台跑的服务：双击 stop.bat

三、日志
-----------------------------------------------------
所有输出都在：data\logs\myhub-collector.log
  - 命令行的 print、程序里的 logging、门户后台任务的输出，全都写进这一份
  - 超过 10 MB 自动轮转，保留 myhub-collector.log.1 / .2 / .3
  - 排查「采集失败」「下载报错」时先看这里

四、目录说明
-----------------------------------------------------
app\                    程序本体
runtime\                自带的 Python 运行时与依赖（不要删、不要改）
data\                   数据目录
  collector.db            数据库（订阅源 / 内容 / 下载记录 / 定时计划）
  credentials\            三个平台的登录态
  browser\                登录与抖音抓取用的浏览器 profile
  downloads\              下载的成品文件（.env 里 DOWNLOAD_DIR 可改到别的盘）
  reports\                每日 HTML 报告（.env 里 REPORT_DIR 可改到别的盘）
  logs\                   日志
  serve.port              当前门户端口（服务运行时才有，关了会删掉）
  autostart.pyw           开机自启用的启动脚本，由页面开关自动生成，不要手动改
  tools\deno\             YouTube 解 JS 挑战用的 Deno（首次用到时自动下载）
.env                    配置文件，门户「环境配置」页可直接改
start.bat               一键启动门户（带窗口）
start-background.vbs    后台启动（无窗口）
install-autostart.vbs   注册开机自启（备用，一般用页面开关）
uninstall-autostart.vbs 取消开机自启（备用，一般用页面开关）
stop.bat                停止后台运行的服务
README.md               项目完整说明（命令、配置项、设计要点）

五、常见问题
-----------------------------------------------------
· 页面打不开：先看 data\logs\myhub-collector.log。最常见的是「端口 17865 不可用」——
  说明端口被占用或被系统临时保留，日志里给了换端口的命令和查占用的命令
· 提示找不到浏览器：装个 Chrome 或 Edge，或在 .env 里把 BROWSER_CHANNEL 改成 msedge / chromium
· YouTube 只能拿到封面图：缺 Deno，联网后双击 start.bat 启动一次，或在门户里按提示补装
· 登录态过期：门户「概览」页重新点「登录」，或在命令行跑
  runtime\python.exe -m app login all
· 换电脑 / 换目录：整个文件夹拷过去即可，路径都是相对的；相对路径以本文件夹为基准
