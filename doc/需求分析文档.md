## 1. 项目概述

### 1.1 项目背景

个人数字资产（视频、小说、漫画）分散在本地磁盘、NAS、WebDAV 网盘等多个位置，同时日常关注的内容创作者动态分散在 B 站、抖音、YouTube 等多个平台。需要一套**统一的自托管系统**，将**文件管理、流媒体播放、在线阅读、订阅动态聚合**整合到一起，实现"一个入口，全部内容"。

原有 Web 版（Vue3 + NestJS）已完成核心功能，本次进行全面架构升级：
- **后端**：从 NestJS（Node.js）迁移到 **Go Gin**，获得更好的性能、更低的内存占用、原生编译部署。
- **前端**：从 Vue3 Web 改为 **Flutter**，一套代码覆盖 Android / iOS / Windows / macOS / Linux / Web 六大平台。

### 1.2 项目目标

1. **全栈重写**：后端 Go Gin + 前端 Flutter，全新架构。
2. **跨平台客户端**：Flutter 一套代码运行于手机、平板、桌面、Web。
3. **统一接入多种存储路径**（本地路径、WebDAV、OpenList 等），提供文件管理能力。
4. **支持视频/音频流式在线播放**，记录播放进度。
5. **支持 txt / epub 小说流式在线阅读**，记录阅读进度。
6. **支持漫画（zip/cbz/rar/epub）流式在线阅读**，记录阅读进度。
7. **聚合各平台关注创作者的动态**，每日定时入库，按序消费并记录浏览进度。
8. **页面划分为阅读 / 动态 / 浏览 / 设置四大模块**。
9. **响应式布局**，手机/平板/桌面自适应。
10. **内置浏览器**：PC（Windows）/ iOS 端新增"浏览器"页签，支持多标签、书签、历史记录（M6）。

### 1.3 用户画像

单一用户（站长本人），自托管部署，无多租户需求，但需要简单的访问鉴权防止公网暴露。

### 1.4 名词定义

| 名词 | 说明 |
| --- | --- |
| 路径源（Source） | 一个已连接的存储位置，如本地目录、WebDAV 服务器 |
| 回收站（Recycle Bin） | 删除文件的临时存放区，可还原或彻底删除 |
| 动态项（Feed Item） | 一条来自订阅平台的更新内容（视频/音频/图文） |
| 阅读进度（Progress） | 小说章节位置、漫画页码、视频播放时间点的统称 |

### 2.2 通用框架（F-001）

#### 2.2.1 导航架构

Flutter 采用 **Material 3 NavigationBar + NavigationRail** 自适应布局：

| 平台 | 导航方式 | 说明 |
| --- | --- | --- |
| 手机（竖屏，<600px） | 底部 `NavigationBar` | 阅读 / 动态 / 浏览 / 浏览器 / 我的 五个主 Tab，顶栏右侧头像菜单 |
| 平板（600~840px） | 左侧 `NavigationRail`（仅图标） | 阅读 / 收藏 / 动态 / 浏览 / 浏览器 / 设置 |
| 桌面（>840px） | 左侧 `NavigationRail`（展开标签） | 同平板，始终显示标签文字 |

> "浏览器"页签仅在 PC（Windows）/ iOS 平台显示，其余平台隐藏（受 WebView 能力限制）。

**导航项**：
- 阅读（`library_books` 图标）
- 收藏（`star` 图标）
- 动态（`bolt` 图标）
- 浏览（`folder` 图标）
- 浏览器（`globe` 图标，仅 PC / iOS 平台显示）
- 设置（`settings` 图标，桌面/平板左侧底部）
- 左下角：设置 + 主题切换两个独立图标按钮

#### 2.2.2 页面保活

- 使用 `IndexedStack` 保持 Tab 页面状态。
- 视频/音频播放器使用独立全屏路由，不随 Tab 切换销毁。
- 迷你播放器使用全局 `Overlay`，跨页面存在。
- 浏览器标签页会话由全局 Provider 持有，切页签不销毁。

#### 2.2.3 主题系统

**亮色主题**：蓝白主调——主色 `#2563eb`，背景 `#eef4fb`，卡片纯白。

**暗色主题**：纯黑背景 `#000000`，卡片 `#121212`，导航栏 `#0a0a0a`。
- 沉浸式场景（播放器、阅读器）自动使用纯黑背景。
- 主题切换持久化到 `SharedPreferences`，支持跟随系统。
- theme-color 始终为 `#000000`（iOS Safari 顶部状态栏兼容）。

### 2.3 浏览模块（文件管理）

#### F-101 路径源连接管理

- 支持添加以下类型路径源：
  - **本地路径**：服务器本地磁盘目录（需配置根目录白名单，防越权访问）。
  - **WebDAV**：填写服务器地址、账号、密码，支持连接测试。
  - **OpenList（可选）**：间接接入阿里云盘、OneDrive、Google Drive、S3 等几十种存储。
- 路径源以"虚拟挂载点"形式呈现，如 `/nas`, `/local-books`。
- 支持编辑、删除、启用/禁用路径源。

#### F-102 文件与文件夹浏览

- 列表 / 网格两种视图，支持按名称、大小、修改时间排序。
- 面包屑路径导航，支持搜索当前目录。
- 文件类型识别并展示对应图标/缩略图（视频生成封面缩略图）。

#### F-103 文件上传

- 支持多文件上传、显示进度条。
- 大文件分片上传（P1），失败重传。
- 桌面端支持拖拽上传。

#### F-104 / F-105 移动、复制、重命名

- 支持单选/多选后在同一路径源内移动、复制、重命名。
- 跨路径源移动通过服务端流式中转（不落地临时文件）。

#### F-106 删除与回收站

- 删除操作默认进入回收站（逻辑删除）。
- 回收站支持：还原、彻底删除、清空、自动清理（可配置保留天数，默认 30 天）。
- 本地路径：回收站为挂载点下的 `.trash` 目录；WebDAV：移动至远端指定回收目录。

#### F-107 文件收藏

- 浏览页文件/文件夹可标记收藏，支持取消；收藏记录持久化存储。
- 收藏为独立模块页，网格/列表视图切换，按类型图标展示，卡片整体可点击。
- 点击收藏条目直接进入对应播放器/阅读器；与浏览页星标状态双向同步。

### 2.4 阅读模块

#### F-201 / F-206 视频/音频流式播放

**技术方案**：Flutter 端使用 `media_kit`（基于 libmpv + FFmpeg），全格式支持。

- 浏览器端直接流式播放，支持 HTTP Range 请求实现拖动进度条（秒开、边下边播）。
- media_kit 原生支持 mp4/webm/mkv/avi/mp3/m4a/flac 等格式，**无需后端实时转码**。
- HLS 转码作为兼容性兜底（部分不兼容格式）。
- 记录播放进度，下次自动续播。
- 支持倍速（0.5x ~ 2.0x）、字幕轨（内嵌/外挂 srt、ass 转 webvtt）。
- **音频唱片封面模式**：封面图片旋转动效、标题/作者信息，控制栏与视频一致。
- **键盘控制**（桌面端）：`←`/`→` 快退/快进、`↑`/`↓` 调节音量、`空格` 播放/暂停、`Esc` 退出播放器。
- **手机端手势**：
  - 水平滑动：调节进度
  - 右侧竖滑：调节音量
  - 左侧竖滑：调节亮度
  - 双击左右：快退/快进 10s
  - 调节时屏幕中央悬浮胶囊实时反馈（进度时间/音量%/亮度%）
- **迷你播放器**：底部迷你条（可拖拽关闭），跨页面保持。

#### F-207 视频/音频播完推荐下一个

- 播放结束后，在当前目录按当前排序查找下一个同类型文件。
- 底部弹出"下一个：xxx"提示条，5 秒倒计时自动播放，点击立即播放。

#### F-202 / F-203 小说流式阅读

- **txt**：后端按章节/分页切分，前端按需加载（流式），不一次性读取全文件；自动识别常见编码（UTF-8/GBK/Big5）。
- **epub**：后端解包提供资源接口，前端自行渲染，按需加载章节。
- 阅读器功能：字体大小、行距、主题（日间/夜间/护眼）、翻页/滚动模式、目录跳转。
- 章节列表缓存，记录每本书的阅读位置（章节+偏移）。
- Flutter 端使用 `PageView`（翻页模式）或 `ListView`（滚动模式），思源宋体用于正文。

#### F-204 漫画流式阅读

- 支持格式：zip / cbz / rar（cbr）/ epub（图集型）。
- 后端按需从压缩包中解出单页图片流式返回，不整包解压到磁盘；页序按自然排序（natsort）。
- 阅读模式：单页、双页、条漫（纵向连续滚动）；支持预加载前后 3 页。
- 记录阅读页码进度。
- `InteractiveViewer` 支持双指缩放。

**漫画识别策略**：
1. **扩展名优先**：`.cbz` / `.cbr` 直接按漫画处理。
2. **内容嗅探兜底**：图片占比 ≥ 90% 且文件名呈自然序列时判定为漫画。
3. **目录级约定**：路径源可标记为"漫画库"。
4. **手动覆盖**：右键/长按菜单提供"以漫画阅读打开"。

#### F-208 漫画翻完推荐下一本

- 翻到最后一页时，底部弹出"下一本：xxx"提示，5 秒倒计时自动打开。

#### F-205 阅读进度

- 首页（阅读模块主界面）展示"正在阅读"列表：封面、标题、类型徽标、进度条、最后阅读时间。
- 点击条目直接跳转到对应阅读器并恢复进度。
- 支持手动将条目标记为"已读完"并从列表移除。

### 2.5 动态模块（二期）

#### F-301 订阅源管理

- 支持添加订阅源：B 站 UP 主、YouTube 频道、抖音博主。
- 每个订阅源可单独启停、设置抓取频率。

#### F-302 AI 定时抓取入库

- 后端定时任务（Go cron）触发抓取，将订阅源更新解析为统一动态项结构入库（SQLite）。
- **抓取方式采用 AI Agent 实现**：使用自托管的 OpenClaw，由其 Agent Browser 能力以真人浏览方式打开创作者主页，再由 LLM 将页面内容按预定义结构抽取为动态项。
- 平台适配以"技能 + 抽取提示词"形式维护，平台改版仅需调整提示词，无需修改代码。
- 对提供官方 RSS 的平台（如 YouTube）保留免费兜底通道。
- 去重：以平台 + 内容 ID 作为唯一键。

#### F-303 动态展示与进度

- 动态流按**发布时间降序**展示（最新在顶部），向下滚动自动加载更早内容（无限滚动）。
- 卡片包含：平台徽标、作者、封面/缩略图、标题、发布时间、内容类型（视频/音频/图文）。
- 记录"当前浏览进度"：上次阅读位置锚点，下次进入自动定位。
- 视频/音频类动态可内嵌播放（统一播放器）或跳转原站。

#### F-304 稍后观看（动态收藏）

- 每条动态提供"稍后观看"图标按钮（书签），收录/取消。
- 动态页顶栏提供带数量角标的图标入口，点击展开稍后观看列表。
- 稍后观看列表持久化存储，与动态卡片按钮状态双向同步。

### 2.6 浏览器模块（F-601 ~ F-605）

> 仅 PC（Windows）与 iOS 端启用"浏览器"页签，其余平台隐藏入口。

#### F-601 内置浏览器核心

**技术方案**：`flutter_inappwebview`（iOS → WKWebView；Windows → WebView2 / Edge 内核，endorsed 官方实现包）。

- **地址栏**：URL 智能识别（合法 URL 直接导航，非 URL 输入走默认搜索引擎）；展示当前页域名与安全图标（HTTPS 锁形）；聚焦时全选编辑。
- **导航控制**：后退 / 前进 / 刷新 / 停止，按历史栈状态禁用。
- **加载进度条**：地址栏下方 2px 蓝色进度条。
- **多标签页**：
  - PC 端：Chrome 风格顶部标签栏（favicon + 标题 + 关闭按钮，新建/关闭/切换，中键关闭）。
  - iOS 端：Safari 风格标签管理页（卡片网格、无痕开关）。
  - 标签页状态全局保活，切页签不销毁。
- **错误页**：加载失败 / SSL 错误提示 + 重试按钮。
- **弹窗策略**：`target=_blank` / `window.open` 一律新标签页打开。
- **键盘快捷键**（PC）：`Ctrl+T` 新标签、`Ctrl+W` 关标签、`Ctrl+L` 聚焦地址栏、`Ctrl+R` 刷新、`Alt+←/→` 后退/前进。
- **iOS 手势**：侧滑返回上一页（历史栈为空则退出页签）。
- **下载链接**：一期不内建下载管理，引导系统浏览器打开。
- **Windows 依赖**：WebView2 Runtime（Win10/11 一般随 Edge 自带），启动时检测、缺失引导安装。

#### F-602 起始页与快捷入口

- 新标签页：默认搜索引擎大搜索框 + 常用站点快捷入口网格。
- 快捷入口支持添加 / 编辑 / 删除 / 拖拽排序，经后端持久化（跨端同步）。
- 首次启动预置默认入口（常用自托管面板等）。

#### F-603 书签与历史

- 地址栏星标一键收藏 / 取消，已收藏高亮。
- 书签管理页：列表 / 搜索 / 编辑（标题、URL）/ 删除。
- 历史自动记录（标题 + URL + favicon，前端节流上报），按日分组展示，支持搜索、单条删除、清空。
- 无痕模式：当前会话不记录历史。
- 数据存储于后端（与收藏 / 进度一致的跨端同步理念）。

#### F-604 与 myhub 内容联动（二期）

- 任意页面可通过菜单"收录到稍后观看"（依赖 M5 动态模块）。
- UA 切换：桌面版 / 移动版（会话级菜单 + 设置页默认值）。
- 动态模块"跳转原站"改为内置浏览器打开。

#### F-605 浏览器设置

- 默认搜索引擎（Google / Bing / 百度 / 自定义 URL 模板）。
- 默认 UA 偏好（跟随平台 / 桌面 / 移动）。
- 清除浏览数据：缓存 / Cookie / 历史。

### 2.7 设置模块

- **路径源设置**：路径源的增删改查。
- **阅读器设置**：默认字号、主题、翻页模式、漫画阅读方向。
- **播放设置**：默认倍速、转码质量偏好。
- **动态设置**：抓取频率、保留条数上限、各平台凭据配置。
- **安全设置**：登录密码修改。
- **系统信息**：存储用量、任务运行日志。

### 2.8 多端适配（F-501）

| 平台 | 导航 | 手势 | 特殊适配 |
| --- | --- | --- | --- |
| Android | 底部 NavigationBar | 系统返回手势 | 边缘到边缘、状态栏沉浸（无浏览器页签） |

### 5.3 核心设计：存储适配器接口

```go
// adapter/adapter.go
type FileEntry struct {
    Name    string    `json:"name"`
    Path    string    `json:"path"`
    IsDir   bool      `json:"isDir"`
    Size    int64     `json:"size"`
    ModTime time.Time `json:"modTime"`
    Ext     string    `json:"ext"`
}

type IStorageAdapter interface {
    List(dir string) ([]FileEntry, error)
```

### 5.4 流式播放设计

- **直通模式**：mp4/webm/mp3/flac → Go 后端透传 + `Accept-Ranges` 支持，Flutter media_kit 直接播放。
- **转码模式**（兜底）：不兼容格式 → FFmpeg 子进程实时转封装为 HLS（`-c copy` 优先）。
- 转码任务按需启动，空闲 5 分钟自动回收；缩略图由 FFmpeg 定时抽帧生成并缓存。

### 5.5 流式阅读设计

- **txt**：首次打开时后台建立章节索引（正则识别"第x章"等标题模式），索引缓存入库；按章节请求对应字节区间，大文件秒开。
- **epub**：后端按需解包（epub 本质是 zip），目录/章节/资源均通过接口提供。
- **漫画**：请求第 N 页 → 后端从压缩包中央目录定位该页图片 → 流式返回；前端预取 N±3 页。

## 7. 风险与约束

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| Go 生态部分库不如 Node.js 丰富 | 部分功能开发周期延长 | 优先使用标准库，epub/压缩包等用 Go 原生实现或 CGo 桥接 |
| media_kit 包体积大 | APK 增大 15MB+ | 可接受；按平台拆分编解码器 |
| RAR 解压在 Go 中支持有限 | 部分漫画无法读取 | 调用系统 unrar 命令或提示用户转 zip |
| 抖音/B站反爬严格 | 动态抓取失效 | AI Agent 真人浏览器访问，天然抗反爬 |
| OpenClaw 服务不可用 | 动态停止更新 | 容器健康检查 + 自动重启；官方 RSS 平台走兜底通道 |
| Go 后端需对接 FFmpeg | 转码复杂度 | 使用 `os/exec` 调用 FFmpeg 子进程，与 Node.js 版逻辑一致 |
| Flutter 桌面端生态不如 Electron | 部分桌面特性缺失 | 优先保证移动端体验，桌面端作为增强 |
| Windows 缺少 WebView2 Runtime | PC 端浏览器页签不可用 | 启动时检测并引导安装（Win10/11 一般随 Edge 自带） |
| flutter_inappwebview Windows 实现较新 | 桌面端 WebView 特性缺失/兼容问题 | 集中封装 BrowserView；必要时 PC 端降级隐藏页签，不阻塞其他模块 |
| iOS 纯浏览器类应用审核敏感 | App Store 上架受阻 | 浏览器为附属功能，应用主体是个人内容中心；自托管分发不受影响 |
