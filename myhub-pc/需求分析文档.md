## 1. 项目概述

### 1.1 项目背景

MyHub 已有两代形态：

1. **Flutter 全栈版**（Go 后端 + Flutter 六端客户端）——已废弃，其「体验优化 / bug 修复」经验沉淀进 iOS 版文档。
2. **iOS 原生版**（`myhub-ios`，Swift + SwiftUI）——纯本地化、无服务器，客户端直连 WebDAV / SMB，内置全格式播放器、小说/漫画阅读器、内置浏览器。**功能已基本完工**（TODO 0~11 章全部完成，仅动态模块与部分平台项未做）。

本项目 `myhub-pc` 是 **MyHub 的第三代形态：桌面端（Windows + macOS）**，目标是把 iOS 版的**全部能力**原样移植到桌面，并补齐桌面平台特有的交互与系统集成。

- **去服务器化**：延续纯本地架构，不依赖任何自托管后端。
- **本地直连存储**：桌面端直接连接 WebDAV / SMB 等网络存储，在本机完成目录浏览、流式读取、解析与播放。
- **单一代码库双平台**：Windows 10+ 与 macOS 12+ 同一套代码、同一套数据模型与业务逻辑，仅平台适配层分叉。

保留并完整移植四大内容模块：**漫画、视频、音频、小说**，以及**内置浏览器**与**动态**模块（动态后续通过对接外部 API 实现，本期预留接口与占位，候选 API 为仓库内 `myhub-feed` Python/FastAPI 服务）。

### 1.2 项目目标

1. **功能对齐**：iOS 版 TODO 中已勾选的每一条（含 130 条体验优化/bug 修复）在 PC 端都有对应实现或明确的桌面等价方案。
2. **纯本地应用**：无服务器端，所有数据（配置、进度、收藏、书签、历史、缓存、索引）保存在本机用户数据目录。
3. **原生网络存储直连**：WebDAV（含内外网双地址路由）、SMB2/3、本地磁盘路径；预留 FTP/SFTP/NFS 适配器扩展点。
4. **全格式媒体播放**：硬解优先 + 软解兜底，网络串流边下边播分片缓存，精准断点续播。
5. **完整内容模块**：漫画、视频、音频、小说、内置浏览器全部支持；动态模块预留接口。
6. **桌面原生体验**：键鼠交互（右键菜单 / hover / 滚轮 / 拖拽 / Ctrl·Shift 多选）、完整快捷键体系、多窗口与托盘、系统媒体控制集成、多显示器与 HiDPI。

### 1.3 用户画像

单一用户（设备持有者本人），个人自用，无多租户、无账号体系。网络存储凭据由用户在应用内配置，安全存储于 **Windows Credential Manager / DPAPI** 或 **macOS Keychain**。

### 1.4 与 iOS 版的核心差异

| 维度 | iOS 原生版 | 本 PC 桌面版 |
| --- | --- | --- |
| 平台 | iOS 16+（iPhone / iPad） | Windows 10 1809+ / macOS 12+ |
| UI 框架 | SwiftUI + UIKit 桥接 | **QML + Qt Quick**（业务层 C++20，见 §4） |
| 状态绑定 | `ObservableObject` + `@Published` + 通知广播 | `QObject` + `Q_PROPERTY` + 信号槽 + `QAbstractListModel` |
| 文本排版 | CoreText（`CTFramesetter` / `CTLine`） | **`QTextLayout` / `QTextLine`**（等价能力，分页与锚点算法可一比一移植） |
| 内置浏览器 | WKWebView | **QtWebEngine**（内置 Chromium，两端同一内核） |
| 导航 | iPhone 底部 TabView / iPad NavigationSplitView | 左侧固定侧边栏 + 内容区（窄窗口折叠为图标栏） |
| 主交互 | 触控手势（滑动 / 长按 / 双指缩放） | 键鼠（右键 / hover / 滚轮 / 拖拽 / 快捷键），触控屏为可选增强 |
| 播放硬解 | AVPlayer / VideoToolbox | 平台硬解（D3D11VA / DXVA2 on Win，VideoToolbox on mac） |
| 播放软解 | MobileVLCKit | libmpv / libVLC（桌面版） |
| 画中画 | AVPictureInPictureController | **桌面置顶迷你悬浮窗**（独立 always-on-top 窗口） |
| 后台播放 | AVAudioSession + 后台模式 | 窗口最小化/托盘常驻即可继续播放，无需特殊授权 |
| 锁屏控制 | MPNowPlayingInfoCenter / MPRemoteCommandCenter | **Windows SMTC** / **macOS MPNowPlayingInfoCenter(AppKit)** + 媒体键 |
| 亮度调节 | `UIScreen.brightness` 系统亮度 | **窗口内亮度蒙层**（不改系统亮度） |
| 音量调节 | MPVolumeView 系统音量联动 | 播放器内部音量为主 + 可选系统音量联动 |
| 凭据存储 | Keychain | Windows Credential Manager / DPAPI，macOS Keychain |
| 应用锁 | Face ID / Touch ID | Windows Hello / macOS Touch ID，回退本地 PIN |
| 文件选择 | UIDocumentPicker / PhotosPicker | 系统文件对话框；**拖拽文件进窗口**上传；相册概念不适用（移除） |
| 本地目录授权 | Security-Scoped Bookmark | 直接存绝对路径（macOS 沙盒分发时仍用 bookmark） |
| 横竖屏 | OrientationController 方向掩码 | **窗口全屏 / 还原 / 尺寸记忆**，无方向概念 |
| 数据目录 | App 沙盒 Documents / Caches | `%APPDATA%\MyHub` + `%LOCALAPPDATA%\MyHub\Cache`；`~/Library/Application Support/MyHub` + `~/Library/Caches/MyHub` |
| 分发 | App Store / TestFlight | Windows MSIX·NSIS 安装包 + 自动更新；macOS DMG + 公证（可选 Mac App Store） |
| AirPlay | `allowsExternalPlayback` | 不实现（可选 DLNA 投屏，列为 P3） |

### 1.5 名词定义

| 名词 | 说明 |
| --- | --- |
| 连接源（Connection） | 一个已配置的存储位置：本地磁盘目录、WebDAV、SMB 共享等 |
| 挂载点（Mount Point） | 连接源在应用内呈现的虚拟入口，如 `/NAS`、`/WebDAV-A` |
| 内外网路由（Route） | 同一 WebDAV 连接源配置内网地址 + 外网地址，启动时竞速探测并锁定可达地址 |
| 边下边播（Progressive Cache） | 网络串流时按需下载并缓存分片，实现秒开、拖动与断点续播 |
| 回环串流代理（Local Stream Proxy） | 本机 `127.0.0.1` HTTP 服务，把存储适配器的 Range 读取统一暴露为 HTTP 源给解码器 |
| 阅读进度（Progress） | 小说锚点、漫画页码、视频/音频播放时间点的统称 |
| 锚点（Anchor） | 排版无关的进度定位结构（小说：章序 + 段序 + 段内偏移 + 文本片段；漫画：页码 + 页内偏移） |
| 文件指纹（Fingerprint） | `fileSize + modTime`，用于校验文件是否被替换，防止进度/索引错乱 |
| 迷你播放器（Mini Player） | 收起后的常驻播放条（嵌在主窗口底部）或独立置顶悬浮小窗 |
| 动态项（Feed Item） | 一条来自外部平台的更新内容（本期预留） |

### 2.2 通用框架（PC-001）

> 📐 **页面原型**：[`prototype/01-shell-navigation.html`](prototype/01-shell-navigation.html) —— 侧边栏三断点、标题栏、mini 播放条、暗色主题、启动 Loading、应用锁

#### 2.2.1 窗口与导航架构

桌面端采用 **单主窗口 + 左侧侧边栏** 布局，随窗口宽度自适应：

| 窗口宽度 | 导航形态 | 说明 |
| --- | --- | --- |
| ≥ 1100px | 展开侧边栏（图标 + 文字，宽 200px） | 默认形态 |
| 760 ~ 1100px | 折叠侧边栏（仅图标，宽 64px，hover 浮出文字） | 自动折叠，可手动固定 |
| < 760px | 侧边栏抽屉式（汉堡按钮唤出覆盖层） | 小窗/分屏场景 |

**导航项**（与 iOS 一致，桌面一次性全部展示，无 iPhone/iPad 之分）：
阅读 / 收藏 / 动态 / 浏览 / 浏览器 / 设置。

- 侧边栏底部常驻：**头像入口**（点击直达个人主页）+ 当前缓存占用摘要（可选）。
- 侧边栏选中项：浅蓝胶囊高亮（与 iOS 一致）。
- **重复点击当前导航项** → 回到该模块起始页（浏览页回到连接源选择列表），与 iOS `AppRouter.reselect` 等价。

#### 2.2.2 页面保活与全局播放

- 各模块页面**常驻不销毁**，切换导航保留滚动位置、搜索词、选择态（与 iOS 保活等价）。
- 播放器、小说阅读器、漫画阅读器、纯文本阅读器为**四条独立的全屏路由**（覆盖内容区或整窗沉浸），不随导航切换销毁。
- **迷你播放器**：主窗口底部常驻播放条（跨页面存在，可展开回全屏、可拖拽/点击关闭）；另可「弹出为独立置顶小窗」（见 PC-603）。
- 浏览器标签会话由全局 Store 持有，切换导航不销毁 WebView，保持导航历史栈。

#### 2.2.3 主题系统

**亮色**：主色 `#2563eb`，页面背景**纯白** `#ffffff`，卡片白 + 极浅描边 `#edf0f3`。
**暗色**：纯黑背景 `#000000`，卡片 `#121212`，侧栏 `#0a0a0a`，描边 `#262626`。

- 沉浸式场景（播放器、阅读器）统一纯黑背景。
- 主题（亮 / 暗 / 跟随系统）持久化；跟随系统时监听 Windows「应用模式」与 macOS 外观变化实时切换。
- Windows 下可选跟随系统强调色（P3）。

#### 2.2.4 启动流程

1. 显示启动 Loading 动画（品牌图标 + 旋转），**不得出现长白屏**。
2. 初始化日志与崩溃捕获 → 打开/迁移数据库 → 预载收藏与浏览器数据 → 连接源启动探测（内外网竞速）→ 缓存全局配额兜底淘汰。
3. 若启用应用锁，先弹出全屏锁定遮罩验证身份。
4. 恢复上次窗口尺寸/位置/最大化状态、上次浏览目录、浏览器标签会话。

### 2.3 本地数据存储（PC-002）

| 数据类别 | 存放位置 |
| --- | --- |
| 结构化数据（连接源、收藏、阅读进度、小说索引、书签、历史、快捷入口、下载任务、动态项） | SQLite 数据库 `myhub.sqlite`（Win：`%APPDATA%\MyHub\`；mac：`~/Library/Application Support/MyHub/`） |
| 偏好设置 | 键值存储（JSON / SQLite 配置表），与 iOS `UserDefaults` 键名保持一致，便于配置互导 |
| 敏感凭据 | Windows Credential Manager（或 DPAPI 加密本地文件）/ macOS Keychain；key 约定 `conn.<id>` |
| 可重建缓存（分片、封面、漫画解压页、小说章节/索引、目录列表） | Win：`%LOCALAPPDATA%\MyHub\Cache\`；mac：`~/Library/Caches/MyHub/` |
| 日志与崩溃报告 | Win：`%APPDATA%\MyHub\Logs\`；mac：`~/Library/Logs/MyHub/` |
| 下载落地目录 | 默认「下载/MyHub」，可在设置中修改 |

要求：

- **缓存与进度分离**：进度不可丢，索引/缓存丢失可重扫重建。
- **数据库迁移**：与 iOS 同构 Schema + 版本化迁移器（`v1_initial`、`v2_reading_fingerprint`…），保证两端数据模型一致。
- **数据导入导出**：导出 JSON 配置快照（连接源 + 全部偏好，**不含明文密码**），可与 iOS 端互导（格式版本号兼容）；导入按挂载点 upsert 并返回「新增 N / 更新 N」。
- **自动备份**：数据库定期（每日/每次启动）备份到数据目录 `backup/`，保留最近 7 份。

### 2.4 浏览模块（文件管理）

#### PC-101 连接源管理

支持的连接源类型：

- **本地路径**：任意本机目录（Windows 盘符路径 / macOS POSIX 路径），通过系统目录选择对话框添加；macOS 沙盒分发时保存 Security-Scoped Bookmark。
- **WebDAV**：外网地址、**内网地址（可选）**、账号、密码、根路径，支持 HTTPS、自签证书信任开关、连接测试。
- **SMB**：服务器地址、共享名、账号/密码或访客、域（Workgroup），支持 SMB2/SMB3。
- **可扩展**：FTP / SFTP / NFS 以协议适配器形式预留（枚举保留，工厂抛「暂不支持」）。

能力要求：

- 连接源以「虚拟挂载点」呈现（`/NAS`、`/WebDAV-A`）；支持新增、编辑、删除、启用/禁用、连接测试；凭据存系统凭据库。
- **连接状态提示**：测试正常显示**绿点**、异常显示**红点**；状态**持久化缓存**，列表进入时不重复探测，仅用户手动点击「测试连接」或重启应用才重新判定。
- **内外网提示**：测试成功时提示词区分「内网可达 / 外网可达」；**浏览页的连接源卡片与设置页的连接源列表必须显示同一状态**（同一数据源驱动，一处刷新两处同步）。
- **内外网竞速路由（PC-708）**：配置了内网地址的 WebDAV 连接源，启动时做 Happy Eyeballs 竞速探测（内网先发、外网延迟 ~700ms 并发兜底），谁先成功用谁并**锁定**该地址；之后所有请求使用锁定地址，不再每次判定。
- 连接源的凭据/配置**持久保存，不因会话过期被清空**，仅删除连接源时清除凭据。

#### PC-102 文件与文件夹浏览

- **视图**：网格视图 / 列表视图切换，偏好持久化。
- **排序**：名称 / 大小 / 修改时间，升降序；**每个目录独立记忆排序偏好**（按「连接 + 目录路径」存储，上限 500 条 LRU 淘汰，无记录回落全局默认）。
- **路径导航**：顶部操作栏显示**当前目录名**（根目录显示连接名）；跨层级跳转由「返回」按钮 / `Alt+←` / 鼠标侧键 / 面包屑下拉承担。
- **搜索**：当前目录内搜索；搜索框位于内容区顶部，**仅当内容滚动在顶部时显示**，向下滚动超过搜索框高度后带动画隐藏（迟滞判定，避免抖动）；搜索框上下无分割线。
- **下拉/手动刷新**：`F5` / `Ctrl+R` 刷新；刷新中显示进度指示；刷新失败给出轻提示并**保留旧缓存内容**，不得清空列表。
- **状态**：加载 / 空目录 / 搜索无结果 / 错误四态。
- **目录缓存**：目录列表本地缓存（stale-while-revalidate：先出缓存秒开，后台刷新覆盖）；刷新失败不删除缓存。
- **文件类型识别与封面缩略图**：音视频、漫画、图片、epub 均显示封面，浏览页与「正在阅读」页使用**同一封面组件与缓存**；视频抽帧首帧生成缩略图并缓存（含 MP4 `covr` 内嵌封面直取）。
- **封面加载性能（重要）**：封面异步加载、占位先行、失败占位、内存+磁盘双缓存、in-flight 去重、全局并发上限、失败 30s 冷却后重试；**封面加载绝不阻塞点击播放/进入**。
- **状态指示**：
  - 有阅读记录的文件显示**环形进度**（网格：角标位；列表：行尾）。
  - 正在播放的文件：文件名变主色加粗 + 三竖条均衡器动画。
  - 优先级：正在播放 > 进度环 > 无标识；目录不显示。
  - **进入多选模式后进度环/播放动画仍须可见**（与勾选标记并列，不得被顶掉）。
- **列表/网格展示细则**：
  - 文件名行数可配（1~5 行，默认 3），**浏览页网格/列表、收藏页网格/列表、阅读页网格/列表六处全部生效**，修改后立即生效无需重进目录。
  - 列表模式行高较紧凑模式增加 1/4；**行间无分割线**。
  - 视频时长显示在标题下方（不挤占封面、不换行）；不显示文件修改时间；**目录不显示子项数**。
  - 网格卡片标题居中；类型图标与目录图标**去白底、放大**，仅用图标展示。
- **选中/交互效果**：
  - 鼠标 hover 高亮；单击选中、双击打开（可在设置中改为单击打开）。
  - 选中态表现为**轻微放大 + 主色软阴影抬升 + 1pt 细描边**，高亮层内缩圆角（列表行内缩成悬浮片、卡片沿自身圆角），填充不超过 8%，不得出现贴边直角色块。
- **多选**：`Ctrl+单击` 增选、`Shift+单击` 区间选、`Ctrl+A` 全选、框选（橡皮筋）；进入多选态后底部出现操作栏（移动/复制/重命名/下载/收藏/删除），**操作栏不得超出窗口、不得被底部播放条遮挡**。
- **右键上下文菜单**：圆角、带精致弹出动画，定位于鼠标位置（不得偏移）；菜单项包含打开方式、以小说/漫画阅读器打开、纯文本查看、属性、收藏、重命名、移动、复制、下载、定位到原路径、删除；**「多选」项置于首位**。

#### PC-201 / PC-202 视频 / 音频播放

**核心内核**：统一播放门面 + **双引擎解码策略**（与 iOS 同构）。

| 层级 | 说明 |
| --- | --- |
| 硬件解码（优先） | 平台硬解：Windows D3D11VA / DXVA2 / NVDEC，macOS VideoToolbox |
| 软件解码（兜底） | FFmpeg 软解，覆盖 mkv/rmvb/avi/flv/wmv/ts/vob 等及 DTS/TrueHD/E-AC-3 等音轨 |
| 自动切换 | 探测容器/编码选择引擎；**硬解起播失败或「有视频轨无音频轨」时自动回退软解**；用户可强制硬解/软解 |

- **全格式支持**：无需转码，直接播放 mp4/mkv/avi/mov/flv/rmvb/ts/webm/m2ts/wmv/vob 等及各类音轨。
- **网络直连播放**：对 WebDAV/SMB 上的文件流式播放（经回环代理，见 PC-203）。
- **播放能力**：
  - 记录播放进度，下次自动续播；**播放完成后再次点击播放应从头重播**（含从「正在阅读」历史重进）。
  - 倍速 0.5x ~ 3.0x。
  - **字幕**：内嵌字幕轨选择；外挂 srt/ass/ssa 自动匹配同目录同名文件（含 `name.zh.srt` 语言后缀约定，精确同名优先，启动自动加载）；字号/延迟可调；**支持手动加载外部字幕文件**（桌面新增，含拖拽字幕进播放窗口）。
  - **音轨切换**：多音轨选择、音频增益、声道映射；≤1 轨时置灰。
  - **音频唱片封面模式**：封面旋转动效（播放转/暂停冻结）；封面来源为同目录同名图片 / cover / folder / front / ID3 内嵌，无封面显示占位；标题/作者按「作者 - 标题」文件名解析；视频/音频模式按实际媒体轨校正（内嵌 albumart 不算视频轨）。
  - **纯音频播放模式**：视频可切换为「仅音频」（关闭画面解码节电）。
  - **截图 / 截取当前帧**（桌面新增，P2）。
- **交互（键鼠）**：
  - 控制层 3s 自动隐藏（播放中），**鼠标移动/点击立刻显示**（不得延迟）。
  - 点击画面播放/暂停；双击全屏切换；滚轮调音量；`←/→` 快退快进（步长可配，默认 10s）；`Shift+←/→` 精细 5s；长按 `→`（或按住右键）2x 倍速、松开恢复。

  - 调节音量/亮度/进度/倍速时，中央悬浮胶囊显示**数值反馈**（时间 / % / 倍速 / ±秒），0.8s 自动隐去。
  - **亮度**为窗口内蒙层调节（不改系统亮度），范围与小说/漫画阅读器共用同一偏好档位。
  - **界面锁定**：锁定后屏蔽所有交互，中央显示锁图标并自动消失；点击画面重新显示锁图标，点击锁图标解锁。
- **退出与 mini 交互**：
  - 控制栏「退出」按钮为**直接退出**播放器（不进入 mini）；单独提供「进入 mini」按钮（`Esc` 退出全屏，`Ctrl+M` 进 mini）。
  - mini 播放条跨页面保持、可点击展开回全屏（**复用同一会话不重载**）、可关闭；深浅色均带细边框；音频无封面时占位块必须不透明（不得透出边框/背景）。

  - mini 播放条显示实时画面预览（视频）/ 封面（音频，与全屏、系统媒体信息同源）。
- **播放器细节修正**（吸收 iOS 实战经验，逐条验收）：
  - 起播时中央「开始按钮」与「旋转加载圈」不得重叠。
  - 暂停/播放提示图标方向必须正确。
  - 不同分辨率视频（含竖屏视频）正确适配显示比例，不拉伸/不裁切错误。
  - **已缓冲并在播放时不得残留加载菊花**（缓冲恢复须把状态切回播放中）。
  - 连续切换多个视频后，**旧会话的残留网络请求必须全部取消**，不得拖慢新视频起播。
  - 播放中/播放后删除源文件不得因句柄占用而失败（见 PC-106 占用处理）。

#### PC-203 网络串流边下边播缓存 + 精准续播

- **回环串流代理**：本机 `127.0.0.1` HTTP 服务，把存储适配器包装为支持 `GET/HEAD` + `Range/206` 的 HTTP 源，双引擎通用；URL 形如 `http://127.0.0.1:<port>/stream/<session>/<fileName>`。
- **分片缓存**：1MB 分片磁盘缓存 + LRU 淘汰 + 总容量上限 + 单文件上限（总量 1/4，淘汰最远分片）；缓存键含**文件指纹**（size+modTime 变更自动失效）；断点续播复用已持久化分片。
- **Range 读取统一**：WebDAV HTTP Range / SMB 分块统一为可 Range 的数据源。
- **弱网优化（重要）**：
  - 适配器层**真正增量流式下载**（按网络分块持续产出，不得整块下完才返回）。
  - **停滞超时**（15s 内持续收到数据就不超时）+ **断点续传**（超时/中断保留已下载字节、从断点续拉，严禁整块作废重下）+ 连续零进展才退避重试。
  - 解码器侧配置足够的前向缓冲时长（由「预读窗口」设置换算），抗网络抖动。
  - 预取窗口低优先级 + 并发信号量限制，不与关键读取抢带宽。
- **精准续播（重要）**：恢复历史进度时**必须直接从历史位置起播**，不得先从 0 播放再 seek。
- **会话取消**：会话注销时必须置取消标记，阻断排队中的预取任务与去重器后续请求。
- **代理自愈**：进程挂起/系统回收回环套接字后，主动探活（非阻塞 connect + poll），发现僵尸监听即重建并换端口；播放失败若为「回环连接被拒」则换端口重试一次再考虑回退软解。
- **缓存策略**：设置中可查看与清理；超限自动 LRU 淘汰。

#### PC-205 / PC-206 小说阅读

- **txt**：
  - 流式读取，**字节级行扫描**建立章节索引，记录各章标题的全局字节偏移（精确无漂移）；按章 Range 加载，不整本读入。
  - **分章规则引擎**：数据驱动多规则表（「第 x 章/节/回/卷」「Chapter n」「楔子/序章/尾声/番外」等），首字符预筛 + 「选最优规则而非并集」校验（条数/间隔/章长/重复度），命中规则 ID 写入索引供缓存复核；**必须能正确识别第一章**。
  - **编码检测（重要）**：BOM 判定 + 无 BOM 启发式，覆盖 UTF-8 / GBK·GB18030 / Big5 / **UTF-16 LE·BE**；Range 切块时做**码元对齐**；旧缓存编码复核自愈（抽样替换符占比异常则重建）。
  - 索引存库（可重建缓存），带文件指纹校验。
- **epub**：按需解包（Range 读 ZIP，不整包下载），解析 `container.xml` → OPF manifest/spine → NAV(EPUB3)/NCX(EPUB2) 目录；章节 XHTML 按需解析为段落流；封面提取并缓存；**图集型（漫画）epub 判定**（抽样 spine 前若干章：文本极少且插图占比高）→ 提示并一键转交漫画阅读器。
- **阅读器功能**：字号、行距、主题（跟随系统/日间/夜间/护眼）、翻页/滚动模式、亮度（窗口蒙层）、衬线字体（思源宋体，未内置时回退系统宋体）、目录抽屉（当前章高亮跳转）、上一章/下一章、章节 ±1 预加载。
- **排版**：行级分页（按行边界切页，不截断行），标题放大加粗，插图等比嵌入；滚动模式为同一分页结果的连续页块，带页内行映射保证锚点精确。调整字号/行距**不得卡死或造成 CPU 飙高**（增量重排 + 缓存）。
- **进度锚点（重要）**：排版无关锚点，禁止页码/百分比等排版相关锚点：
  - 结构：`章序 + 章标题 + 段落序 + 段内字符偏移（UTF-16 计数）+ 章内偏移 + 后续文本片段（重定位兜底）+ 百分比兜底 + 文件指纹`。
  - **一步定位**：恢复时直接按锚点定位，禁止「先跳章节再定位偏移」两步时序。
  - 兼容 iOS 旧版「纯全局字节偏移」锚点。
  - 文件指纹不匹配时提示并重建索引/归零，防止跳转错乱。
- **离线**：章节解码产物落盘缓存，命中免网络。
- **翻页/滚动的边界安全**：锚点正反向换算统一字符计数单位，含 emoji / 代理对不得越界崩溃。

#### PC-207 漫画阅读

- 支持格式：zip / cbz / rar（cbr）/ epub（图集型）。
- 按需从压缩包解出单页图片（zip 系走 Range 解包，仅拉中央目录 + 目标条目，支持 ZIP64 与 deflate/stored；rar 系走 RAR 解析库，远程源流式落地临时文件并显示下载进度）；页名自然排序。
- **阅读模式**：单页 / 双页（可切换 RTL·LTR 并持久化，默认日漫 RTL）/ 条漫（纵向连续滚动）。
- **缩放**：`Ctrl+滚轮` 1x~4x 缩放、双击放大/还原、拖拽平移；1x 时滚轮/拖拽让位翻页。
- **预加载**：当前 ±3 页（正向翻页前向优先，反向后向优先，最多并发 3）；内存 LRU 保留当前 ±6 页；大图下采样防爆内存。
- **进度记录与恢复（重要）**：记录页码（+ 页内偏移）与文件指纹；下次打开**直接恢复到上次页码**（首次构建即定位，不从第一页开始）；条漫模式恢复页码显示。
- **弱网优化（重要）**：点击漫画文件**先展示 UI 进入加载界面**（解析转圈 / 远程 rar 下载百分比进度），不得「点了没反应」；重复点击防抖去重。
- **控制层**：顶栏（关闭 + 书名 + ⋯ 菜单：模式切换 / 双页方向 / 亮度）+ 底部毛玻璃胶囊（上一页 / 可拖进度轨 / 页码 / 目录 / 下一页，**拖动中只改本地值、松手才跳页**，拖动时气泡跟随）+ 快捷 chip（缩略图面板 / 下一本 / 亮度）。
- **缩略图面板**：页面缩略图网格，点击跳页，按需小尺寸解码 + LRU，不占用阅读解压并发。
- **漫画识别策略**：① 扩展名优先（`.cbz`/`.cbr`）；② 内容嗅探（图片占比 ≥90% 且文件名呈自然序列）；③ epub 图集判定（**目录层预判并缓存**，列目录即显示漫画徽标）；④ 手动覆盖（右键「以漫画阅读打开」）；⑤ 目录级「漫画库」标记。
- **离线**：解压页按「指纹 + 页名」落盘 + 页名清单持久化，缓存优先源秒开、后台补齐，无网可读。

#### PC-208 漫画翻完推荐下一本

- 翻到最后一页时底部弹出「下一本：xxx」提示条，**无倒计时、不自动打开**，需用户点击；可取消；按该目录排序偏好查找。

#### PC-209 阅读进度与「正在阅读」首页

- 列表展示：封面、标题、类型徽标（视频/音频/小说/漫画）、进度（**饼状图 + 下方百分比文字**，文字与饼图间距适中）、最后阅读相对时间（「n 分钟前 / 昨天」）。
- 封面优先复用阅读时提取的缩略图缓存（epub/漫画零网络秒出），否则走统一封面组件；**借助进度记录中的文件指纹**可免 stat 直接命中磁盘缓存秒出，后台再静默校正。
- 网格 / 列表两种视图切换（偏好持久化）；支持多选（`Ctrl`/`Shift`/框选）与右键菜单。
- 点击条目恢复进度进入对应阅读器/播放器（视频/音频精准续播、小说锚点一步定位、漫画恢复页码）。
- **已读完记录保留至用户手动删除**；文案按类型区分：视频「已看完」/ 音频「已听完」/ 漫画·小说「已读完」（默认「已读完」，主色高亮 + 进度满格）。
- 操作：**删除阅读记录**（不影响源文件，有确认说明）、**删除源文件**、定位到原路径、属性；多选支持批量删记录/删源文件。
- **进度上报后自动刷新列表**（统一进度广播通道，无需手动刷新）。
- 空状态提示（图标 + 引导文案）。
- 浏览页删除/移动文件 → 阅读记录同步删除/更新路径；重命名 → 记录同步重命名。

#### PC-210 纯 txt 阅读器

- 作为独立于小说阅读器的第 4 条阅读路由：txt 文件**默认用它打开**（编码检测 + 全文滚动懒加载 + 文本可选中复制 + 查找），**不建索引、不记进度**；需要章节与进度时由右键菜单「以小说阅读器打开」。

### 2.7 浏览器模块（PC-401 ~ PC-404）

> 📐 **页面原型**：[`prototype/06-browser.html`](prototype/06-browser.html) —— 多标签条、悬浮工具栏胶囊、起始页快捷入口、标签网格、历史书签、错误页、下载接管、浏览器设置

**技术方案**：**QtWebEngine**（内置 Chromium，两端同一内核）。能力对照见 §4.2 末表，PC-401~404 全部需求均有对应 API。

#### PC-401 内置浏览器核心

- **地址栏**：URL 智能识别（合法 URL 直接导航，否则走默认搜索引擎）；展示域名与 HTTPS 安全图标；聚焦全选；**输入框宽度必须受控**（不得撑满窗口导致看不到光标）。
- **工具栏**：后退 / 前进 / 刷新·停止 / 地址栏 / 标签数 / 菜单；按历史栈状态启用禁用；按钮按压动画。
  - **修正**：进入新网页后后退按钮必须可用；`Alt+←`/鼠标侧键后退生效；**起始页作为可回退的虚拟第一页**，从起始页导航后仍可回退到起始页；回退到最后一页时**不得关闭标签**。

- **加载进度条**：地址栏下方 2px 主色进度条。
- **错误页**：加载失败 / SSL 错误提示 + 重试。
- **弹窗策略**：`target=_blank` / `window.open` 一律新标签打开。
- **页面内交互**：`Ctrl+F` 页内查找、`Ctrl+±` 缩放、`F5` 刷新、`Ctrl+L` 聚焦地址栏、`Ctrl+T` 新标签、`Ctrl+W` 关标签、`Ctrl+Shift+T` 恢复关闭的标签、`Ctrl+Tab` 切换标签。
- **下拉刷新**：桌面以 `F5`/刷新按钮为主（触控屏可选下拉刷新）。
- **下载**：接管下载到应用下载目录并给出完成提示（桌面端应实现，优于 iOS 的「引导系统浏览器」）。
- **工具栏收起**：桌面端默认常驻；窗口高度不足或进入「沉浸阅读」时可收起为小胶囊，点击恢复。

- **预置逻辑必须在数据库就绪之后执行**，数据库未就绪时不得写入「已预置」标记（避免永久跳过）。

#### PC-403 书签与历史

- 历史：自动记录（标题 + URL + favicon），按日分组，搜索、单条删除、清空。

#### PC-404 浏览器设置

#### 组件规范

- **圆角**：卡片 12px，按钮 20px（胶囊），输入框 8px，悬浮装饰条 26px。
- **描边统一**：底部播放条、工具栏胶囊、多选操作栏、卡片**统一使用同一描边色与 1pt 宽度**（不得各自为政）。
- **阴影**：亮色卡片轻投影（黑 8% / 半径 8 / y3）；暗色以描边区分。
- **图标**：线形风格统一图标集；同类按钮图标视觉体量一致，图标与文字竖排时使用固定槽高对齐。
- **按钮**：主按钮实心蓝，次按钮浅蓝底 + 蓝字；按压缩放 0.975 + 淡填充。
- **进度条**：4px 高，主色；饼状进度用于「正在阅读」。
- **字体**：Windows「微软雅黑 / Segoe UI」、macOS「PingFang SC / SF Pro」；阅读器正文可选思源宋体。
- **弹窗**：确认框一律**完全圆角矩形、居中显示**，不得使用带尖角的锚点气泡。
- **菜单**：圆角 + 精致弹出动画；右键菜单定位于鼠标位置；菜单底部与窗口边缘保持足够间距。
- **动效**：轻量过渡（≤ 200ms）。

#### PC-708 网络自愈与内外网路由（iOS 已实现，文档补录）

- **内外网竞速（Happy Eyeballs）**：内网先发、外网延迟 ~700ms 并发兜底，先成功者锁定；`testConnection` 清锁重判。
- **失败自愈**：仅连接类/网关类错误（超时/DNS/连不上/断网/5xx/非法响应）才回退另一地址或清锁（带 8s 冷却）；404/409/鉴权等业务错误不触发切换。
- **流式读取**不可中途换址，必须先解析路由再选址。
- **休眠/挂起恢复**：系统休眠唤醒、网络切换（Wi-Fi 重连/换网段）后，清除地址锁定并重建回环代理；回到前台/恢复窗口时必做代理探活。
- **网络状态监听**：记录网络路径变化（断网、切换接口、计费/受限网络）用于诊断。
- **目录列举严格校验**：WebDAV 响应解析不到合法 `multistatus` 时必须报错（记录状态码/Content-Type/响应体前缀），**严禁把异常响应当作「空目录」**返回并写入缓存。

## 4. 技术选型

### 4.0 选型结论与依据

**最终选型：Qt 6 + QML + C++（LGPLv3 开源版）。**

四个候选方案（Qt6 / Flutter Desktop / Electron / Tauri）经加权评估后 Qt 胜出，核心依据：

| 依据 | 说明 |
| --- | --- |
| **主体模块优先** | 本应用主体是「个人内容中心」，**播放器是主体、浏览器是附属**（沿用 iOS 需求文档 §7 对本产品的定位判断）。Qt 在播放器上有成熟方案（mpvqt + `QQuickRhiItem`），Electron/Tauri 的强项恰恰在附属模块而弱项在主体模块 |
| **播放器嵌入成熟** | `mpvqt`（**KDE 组织维护**，KDE Haruna 播放器生产使用）把 libmpv 输出接入 Qt Quick 场景图，**视频就是普通 QML Item**；控制层叠加、mini 条实时预览、悬浮小窗复用会话全是普通 UI 代码。无需自研解封装 / A-V 同步 / seek / 缓冲水位 |
| **小说排版可一比一移植** | `QTextLayout::createLine()` + `QTextLine::textStart()/textLength()` 是 iOS CoreText `CTFramesetter`/`CTLine` 的等价物，iOS 的「按行边界切页不截断行 + 页内行映射 + 排版无关锚点」设计可**近乎原样移植**（这是项目逻辑最密的模块之一） |
| **原生库零胶水** | libsmb2 / libarchive / FFmpeg / SQLite 均为 C 库，**直接链接，无 FFI 封送层**；macOS 原生能力可在同工程写 `.mm`（Objective-C++），Windows 可直接用 C++/WinRT，不需要「插件桥接」概念 |
| **浏览器够用** | QtWebEngine 内置 Chromium，PC-401~404 的每一条需求均有对应 API（见 §4.2 对照） |
| **资源达标** | 常驻 120~200MB、冷启动 < 1s，是唯一无需放宽 §3 非功能指标的方案 |
| **成本性质** | Qt 的代价是**确定型**（开发效率低 20~30%、QML 视觉手工量大），而非**风险型**（投入后仍可能做不好）。对「必须做成」的项目，确定型成本优于风险型成本 |

**已知代价（接受）**：开发效率低于 Web/Flutter 系；毛玻璃等视觉效果需平台代码；C++ 崩溃调试成本高；LGPL 合规与 LTS 政策约束（见 §4.5、§7）。

| 层次 | 技术 | 选型理由 |
| --- | --- | --- |
| **语言/UI** | | |

| 决策点 | 选定方案 | 备选 | 结论 |
| --- | --- | --- | --- |
| **UI 框架** | **Qt 6 + QML** | Flutter Desktop / Electron / Tauri | 见 §4.0。四方案加权评分 Qt 4.29 > Flutter+Rust 4.27 > Electron 3.66~3.81 > Tauri 2.9~3.21 |

**要点**：
- **视频是普通 QML Item**：`mpvqt` / `QQuickRhiItem` 把 libmpv 输出接入 Qt Quick 场景图，因此控制层、字幕浮层、手势反馈胶囊、mini 条实时预览、悬浮小窗全部是常规 QML 叠加，**不存在原生子窗口遮挡问题**。
- **统一门面**：QML 只面向 `PlayerCore`（`QObject` + `Q_PROPERTY`），引擎切换对上层透明。
- **数据源抽象**：本地与网络统一为可 Range 读取的数据源；网络源经回环代理 + 分片缓存。
- **缓存**：分片下载 + 磁盘 LRU，支持 seek 定位、断点续播与离线复用，容量可配可清理。
- **线程模型**：网络 IO / 解析 / 缓存写盘在 worker 线程（`QThread` + `QObject::moveToThread` 或 `QtConcurrent`），**严禁阻塞 GUI 线程**；跨线程一律信号槽（`Qt::QueuedConnection`）。

### 4.4 存储适配器接口（与 iOS 同构）

```cpp
struct FileEntry {
    QString   name;
    QString   path;
    bool      isDir  = false;
    qint64    size   = 0;
    QDateTime modTime;
    QString   ext;
};

// Range 流式读取的回调式接口：每收到一块立即回调，支持取消与断点续传
class RangeStream : public QObject {
    Q_OBJECT
signals:
    void data(const QByteArray &chunk);   // 增量产出，不等整块下完
    void finished();
    void failed(const StorageError &e);
public slots:
    void cancel();
};

class StorageAdapter {
public:
    virtual ~StorageAdapter() = default;
    virtual QFuture<QList<FileEntry>> list(const QString &dir) = 0;
    virtual QFuture<FileEntry>        stat(const QString &path) = 0;
    // 支持 Range 的流式读取，供播放器/阅读器按需拉取（start/end 为空表示整文件）
    virtual RangeStream* readStream(const QString &path,
                                    std::optional<qint64> start,
                                    std::optional<qint64> end) = 0;
    virtual QFuture<void> writeStream(const QString &path, QIODevice *src,
                                      qint64 length = -1) = 0;
    virtual QFuture<void> move  (const QString &src, const QString &dest) = 0;
    virtual QFuture<void> copy  (const QString &src, const QString &dest) = 0;
    virtual QFuture<void> remove(const QString &path) = 0;
    virtual QFuture<void> mkdir (const QString &path) = 0;
    virtual QFuture<void> testConnection() = 0;
};
// 实现：LocalAdapter / WebDAVAdapter / RoutedWebDAVAdapter / SMBAdapter
//（预留 FTP / SFTP / NFS）
```

配套类型（移植自 iOS）：
- `StoragePath`：虚拟路径归一化 / join / fileName / parent / ext
- `StorageError`：`InvalidPath / InvalidConfig / NotFound / Http / AuthenticationFailed / UnsupportedProtocol / `**`InvalidResponse`**` / `**`Offline`**` / Underlying`
- `RouteRecoverable`：`invalidateRoute()` / `invalidateAllLocks()`（内外网地址锁定自愈）

### 4.5 许可合规（LGPLv3）

本项目使用 **Qt 开源版（LGPLv3）**，合规要点：

| 义务 | 落地做法 |
| --- | --- |
| **动态链接 Qt 库** | 随包分发 Qt 动态库（Win：`windeployqt` 产出 dll；mac：`macdeployqt` 产出 framework）。**不得静态链接**（静态链接需商业授权） |

| **附许可证副本并明示使用 Qt** | 「设置 → 关于 → 开源许可」页列出 Qt 及其 LGPLv3 全文、libmpv(LGPL)、FFmpeg(LGPL)、libarchive(BSD)、libsmb2(LGPL)、SQLite(Public Domain) 等 |
| **公开对 Qt 本身的修改** | 不修改 Qt 源码（如需修改则需公开该部分） |

**必须规避的 GPL-only 模块**（引入会导致整个应用被要求以 GPL 发布）：

| 模块 | 替代方案 |
| --- | --- |

**分层约定**：
- **QML 只做展示与交互**，不含业务逻辑；所有状态经 C++ `QObject` 的 `Q_PROPERTY` / 信号槽 / `QAbstractListModel` 暴露。
- **`src/core`、`src/domain`、`src/readers` 不得 include 任何 QtQuick/QtGui 头**（仅依赖 QtCore/QtNetwork），保证逻辑层可被单测直接覆盖，也便于未来复用。
- **`src/platform` 是唯一的平台分叉点**，上层只面向其门面接口（`NowPlaying`、`CredentialStore`、`AppLockManager`、`Notifier`、`Revealer`）。

### 5.6 边下边播缓存流程

```
用户拖动进度到 t 秒
   │
   ▼
PlayerCore → 引擎发起 HTTP Range 请求到回环代理
   │
   ▼
LocalStreamProxy → CachedRangeReader 请求 [offset, offset+len)
   │
   ├── 命中分片缓存 → 直接返回给解码器（零网络）
   │
   └── 未命中 → AdapterRangeDataSource.readStream(range)
                 （WebDAV: HTTP Range + 内外网锁定地址
                   SMB:    libsmb2 分块读）
                 ↓ 增量流式下载（停滞看门狗 15s / 断点续传）
                 写入 SegmentCache（磁盘 LRU，键含文件指纹）
                 ↓
                 返回分片给解码器（同时低优先级预读后续窗口）
```

## 7. 风险与约束

### 7.1 技术风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| **SMB（libsmb2）在 Windows 上的构建与分发** | SMB 连接失败或工期延长 | M-1 预研优先验证（vcpkg / 自编译 + 静态归档）；降级备选：引导用户映射网络驱动器后按本地路径访问（`LocalAdapter` 可直接复用） |
| **libmpv 与 `QQuickRhiItem` 的多实例 / HDR / 硬解兼容性** | 播放卡顿、黑屏或 mini 预览失效 | M-1 预研验证三条硬指标；预留 `VlcEngine` 兜底接口；设置提供「强制软解」与渲染后端切换 |
| **QtWebEngine 的 Chromium 版本滞后上游** | 新站点兼容性与安全补丁延迟 | 跟进 Qt 常规版本滚动升级（见下「LTS 政策」）；浏览器为附属模块，影响可控；对关键站点提供「用系统浏览器打开」出口 |
| **QML 视觉还原手工量大**（毛玻璃、浮起抬升、呼吸灯、胶囊描边） | M5 打磨超期 | 优先抽象统一组件（`GlassPanel` / `CellPressHighlight` / `PopupMenu`）一次写好复用；毛玻璃用平台代码（Win `DwmSetWindowAttribute` / mac `NSVisualEffectView`），降级为半透明纯色 |
| **C++ 崩溃排查成本高** | 定位慢、影响迭代节奏 | 首期即接入 `CrashReporter`（Breakpad/Crashpad 或自写信号处理）与分模块文件日志（PC-707），与 iOS 端同等诊断能力 |
| 回环 HTTP 代理被安全软件/防火墙拦截 | 无法播放 | 仅绑定 127.0.0.1、随机端口、健康探活与换端口重试；安装包声明 |
| 行级文本排版精度（与 CoreText 对齐）导致锚点漂移 | 小说进度错位 | 锚点为排版无关结构 + 文本片段重定位兜底；排版变更只影响显示不影响锚点；`QTextLayout` 与 CoreText 的行切分语义在 M-1 预研中对照验证 |
| RAR 解析库授权与跨平台编译 | 漫画部分格式不可读 | libarchive（BSD）优先；失败提示转 zip |
| 包体积（Qt + QtWebEngine + libmpv/FFmpeg） | 安装包 120~200MB | 可接受；`windeployqt`/`macdeployqt` 裁剪未用模块；不使用的 Qt 模块不链接 |
| macOS 公证 / 沙盒限制（本地目录访问、网络） | 分发受阻 | 非沙盒 DMG 分发 + Developer ID 签名公证；如上架 MAS 则补 bookmark 与权限声明 |
| 双端 UI 细节差异（字体度量、滚动、DPI） | 视觉不一致 | QML 自绘 + 统一设计令牌；两端对照回归清单 |
| 纯本地无同步 | 多设备数据不共享 | 本期定位单设备；配置导入导出支持与 iOS 互导；未来可选 WebDAV 配置同步 |

### 7.2 许可与合规风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| **误用 GPL-only Qt 模块** | 整个应用被要求以 GPL 发布 | 建立依赖白名单与 CI 检查：**禁止链接 Qt HTTP Server / Qt Charts / Qt Data Visualization / Qt Lottie / Qt Virtual Keyboard**；HTTP 服务一律用 `QTcpServer` 自写（见 §4.5） |
| **LGPL 合规缺失**（静态链接 / 无许可证声明） | 分发侵权 | 强制动态链接；发布前检查项：动态库随包可替换、「关于 → 开源许可」页包含 Qt 及各依赖许可证全文、明示使用 Qt |
| **Qt LTS 补丁仅商业授权** | 开源版无法长期封板在某个补丁版本 | 不采用长期封板策略，随常规版本（约半年一个）滚动升级；CI 保持可一键切换 Qt 版本构建 |
| Qt 许可政策未来进一步收紧 | 可能被迫商业授权或迁移 | 业务逻辑层（`src/core` / `src/domain` / `src/readers`）禁止 include QtQuick/QtGui，仅依赖 QtCore/QtNetwork，降低未来迁移成本；必要时可评估 Qt for Small Business 档位 |

### 7.3 技术栈存续与监测

| 依赖 | 存续风险 | 监测项 | 触发动作 |
| --- | --- | --- | --- |
| Qt（Qt Group，30 年） | 极低（~1%） | 许可政策公告、常规版本发布节奏 | 政策重大变更 → 评估商业授权或迁移 |
| **mpvqt**（KDE 组织维护） | 低 | 最近提交 ≤ 12 个月 | 超期 → fork 进 `third_party/` 自行维护（封装层代码量可控） |
| libmpv / FFmpeg | 极低 | — | — |
| QtWebEngine | 低（随 Qt） | Chromium 基线版本落后上游代数 | 落后过多且影响使用 → 评估 CEF 替换（接口已抽象） |
| libsmb2 / libarchive | 低 | 最近提交 ≤ 18 个月 | 超期 → vendor 锁定版本 |

**通用对冲措施**（沿用 iOS 端对 `UnrarKit` 的 vendor 实践）：关键原生依赖一律 **vendor 进 `third_party/` 并锁定版本**，上游消失不影响构建。

### 8.4 平台配置要点

**Windows**
- **无需额外运行时**（QtWebEngine 自带 Chromium，不依赖 WebView2 Runtime）。
- 部署：`windeployqt` 产出 Qt 动态库 + QML 模块 + QtWebEngine 资源（`QtWebEngineProcess.exe`、`.pak`、locales）。
- 防火墙：仅本机回环监听，无需入站规则；如被拦截给出提示。
- 文件关联（可选）、单实例（`QLocalServer` 或互斥量）、任务栏进度与缩略图工具栏（P2）。
- 打包：MSIX 或 NSIS；代码签名证书。**保持 Qt 动态库可替换以满足 LGPL 重链接义务**。

**macOS**
- `Info.plist`：`NSAppTransportSecurity`（按需允许 HTTP WebDAV）、`NSLocalNetworkUsageDescription`（SMB 局域网）、`NSUserNotificationsUsageDescription`。
- Entitlements：网络客户端、文件读写（沙盒分发时含 user-selected）、Keychain。
- 部署：`macdeployqt` 打包 framework 与 QtWebEngine 的 Helper 进程；通用二进制（arm64 + x86_64）。
- 原生菜单栏、Dock 菜单、Touch ID（LocalAuthentication）。
- 打包：DMG + Developer ID 签名 + 公证（notarization），QtWebEngine Helper 需一并签名。
