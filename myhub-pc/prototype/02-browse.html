图标与配色纪律：文件类型图标统一为单色线形图标 + 中性占位色（#9CA3AF），不用彩色或 emoji 区分类型； 类型区分依靠图标形状 + 下方文字说明。时长角标与漫画徽标统一为深色半透明底白字，不用品牌色。
封面性能红线（PC-702）：封面异步加载 + 占位先行 + 失败占位 + 内存/磁盘双缓存 + in-flight 去重 + 全局并发上限 + 失败 30s 冷却重试； 封面加载绝不阻塞点击进入播放/阅读。
选中高亮（沿用 iOS 方案 D「浮起抬升」）：内缩圆角高亮 + 轻微放大（列表 1.012 / 网格 1.03）+ 主色软阴影 + 1pt 细描边，填充 ≤ 8%， 不得出现贴边直角色块。
删除占用处理（PC-106）：删除前若待删项正在播放/阅读，先停止会话并等待串流注销（最长 1s）；遇 HTTP 423/409/429/5xx 等占用错误自动退避重试 2 次， 失败提示必须携带具体原因并附「稍后重试」建议。
