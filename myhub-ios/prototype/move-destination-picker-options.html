移动 / 复制 · 目标目录选择器改版

需求②：现有弹层「列表行太矮、排列紧凑、无返回上一级入口」。目标是行高与路径源列表对齐 （路径源行 ≈ 80pt：52pt 缩略图 + 上下 14pt），并在首行加 ..（上一级）行。 下面各方案（含 B 的两个底部操作栏版本）都可直接点击目录名 / .. 行走目录，先体验再选。

💡 原型可交互：点文件夹进入、点「上一级」回退、点面包屑跳层级
方案行高上一级取消 / 确认位置改动量主要取舍
现状44pt仅顶部 ‹ 按钮取消在左上，确认在右上「选择此处」— 行距紧、图标小，长目录名易截断
A 统一行高72pt首行「上一级」取消左上，确认在右上「选择此处」小 只调列表，风险最低；工具栏仍偏拥挤
B 面包屑 + 底部操作栏72pt首行「上一级」+ 面包屑跳级取消 + 确认同在底部操作栏中 路径最清晰，操作集中在拇指区；额外占一条底部栏
B 变体（毛玻璃三键）72pt首行「上一级」+ 面包屑跳级悬浮毛玻璃栏：取消 / 新建 / 确认中 与多选栏同款；确认键权重不够突出
B 变体 2（主键胶囊）72pt首行「上一级」+ 面包屑跳级毛玻璃栏 + 通栏蓝色胶囊中 观感统一且主操作最突出；「新建」文字压缩
C 卡片分组 + 标题区64pt卡片外「上一级」卡片取消左上，确认在底部通栏中大 层次感最好；与路径源列表观感差异较大
共同规则（建议）：
① 行高与路径源列表对齐：图标 44pt（路径源 52pt）+ 上下各 14pt 内边距 = 72pt；名称 16pt 半粗、副标题 11.5pt 灰字（「文件夹」/「上一级」）。
② 分隔线左端缩进 72pt（图标右侧），与 iOS 列表视觉一致，不再通栏切一刀。
③ .. 行仅在非根目录出现；根目录不显示（无可回退层级）。
④ .. 行副标题直接写「回到 /视频」，让用户知道回哪去，而不是只有两个点。
⑤ 空目录不再是一行干巴巴的「无子文件夹」：.. 行仍在，空态文案放列表下方。
⑥ 新建文件夹后自动进入/停留在当前目录并刷新（保持现有行为）。
推荐方案 B：行高与路径源一致 + 首行「上一级」（手指可达区，单手握持也能回退）+ 底部操作栏把「取消 / 移动到此」都放到拇指区， 导航栏只留标题与「新建文件夹」；若希望把所有操作集中到底部，可选 B 变体 2（毛玻璃悬浮栏 + 主键胶囊）—— 外壳与浏览页多选操作栏 selectionBar 完全同款：14pt 圆角、.ultraThinMaterial、0.5pt 描边、黑 12% 阴影、 通栏 padding(.horizontal, 12)，栏高 44pt（7pt 上下内边距 + 20pt 图标 + 10.5pt 文字）。
