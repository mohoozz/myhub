App 图标：白底 + 插图内缩 方案原型v2 · 图标已内嵌

现状：AppIcon.png（1024×1024）是满铺的插画，iOS 套上系统圆角后画面一直顶到四边，在主屏上与其它 App 的「留白 + 居中图形」并排时会显得很满、很挤。
目标：把插图缩小一点、外面加白底（或极浅品牌底），让图标有呼吸感。下面 6 个方案（A–F）都是烘焙进 1024 PNG 的效果（iOS 会再套系统连续圆角），每块都放了主屏实景 + 放大观察条；F 是按你的要求做的「E + 浅蓝底」。
已选定方案 E（白底 + 9% 留白 + 正圆插图，直径约 82%），并已生成到 AppIcon.png（1024×1024、RGB 无 alpha），原图备份在 Tools/AppIcon-source.png。
本页 v2：插画已用 CSS background-image 内嵌（base64 data URI，全页只出现一次），不再引用任何外部文件；若插图区域仍是空白/破图，说明预览器禁止了 data URI，请直接告诉我，我改出 PNG 版对比图。

方案底色插图内缩插图内圆角观感取舍
现状无（满铺）0%0画面顶满四边，最有冲击力与其它 App 并排偏「满」，缩小后细节也更难辨认
A 白底 · 轻内缩纯白12%0（直角）白框 + 方照片，边界干净直角插图与圆角底同框略生硬
B 白底 · 内圆角纯白13%18%（相对插图）白色卡片里嵌一张圆角小图，最像「品牌卡」插图再小一档，画面细节损失一点
C 白底 · 大留白纯白20%22%留白最多、呼吸感最强，主屏上最「安静」插图占比仅 60%，小尺寸下几乎看不清内容
D 品牌浅蓝底#EEF4FB15%20%与 App 内主界面同款浅蓝，品牌一致主屏暖色/深色壁纸下，浅蓝底的冷暖差比白底更明显
E 白底 · 圆形徽标纯白9%50%（正圆）最像「头像/徽标」，最不像截图圆形裁掉四角，构图（右眼、右下脸）会被切
F 浅蓝底 · 圆形徽标#EEF4FB9%50%（正圆）E 换成品牌浅蓝底，圆形徽标 + App 内同色浅蓝与插画边缘对比弱于白底；深/暖壁纸下略偏冷
F2 浅蓝加深 · 圆形徽标#DCE9FB9%50%（正圆）蓝底看得出来，暖色壁纸上也能立住与 App 内 #EEF4FB 页面不同色，内外一致性弱于 F
共同规则：白底为纯 #FFFFFF 不透明（App Store 要求图标无 alpha 通道，现状满铺图也不带透明，改后同样合规）；插图内缩比例、内圆角都烘焙进 1024×1024 PNG， 不能在代码里做（系统直接用这张图套连续圆角）；尺寸实测条里 40px 那一档是主屏「设置/文件夹」级别的最小可见尺寸，用来判断内缩后是否还能看清。
实现方式（选定后）：保留原图备份为 AppIcon-source.png，用 Pillow 脚本（Tools/make_app_icon.py）由原图生成新的 AppIcon.png（白底 + 居中内缩 + 插图圆角），脚本留在仓库便于以后换插画重跑； BrandLogo（启动页 88pt、关于页 64pt）是同一张图，可一并同步，也可只在主屏图标上做（启动页满铺其实不算突兀）。
推荐：B（白底 + 13% 内缩 + 18% 内圆角）——留白足够、插图还看得清、内圆角让画面不与白色直角冲突；想要更安静选 C，想改动最小、只加一道白边选 A； 想要「圆形徽标 + 品牌底色」这一路，E 与 F 只差底色（白 / #EEF4FB），前者更亮、后者内外一致。
