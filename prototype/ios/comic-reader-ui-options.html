漫画阅读器 · 控制层重设计

现状控制层（ComicReaderView.controlsOverlay）是上下两条黑色渐变通栏：顶栏「✕ + 书名 + 模式菜单」，底栏两段「页码 + Slider + 双页方向（细线白点）/ 单页·双页·条漫三个等宽竖排按钮」。
问题：① 渐变通栏与全局「圆角悬浮胶囊 / 毛玻璃」语言不统一；② 模式切换（低频）占据底栏最显眼一行，而跳页、下一本、缩略图（高频）没有入口；③ 系统 Slider 与深色渐变叠在一起观感割裂，进度条无手柄提示、无法「按住拖动看目标页」；④ 顶栏与底栏无圆角/无描边，像纯黑蒙层而不是控件；⑤ 条漫模式下滑动浏览无进度反馈位置。
以下为「现状 + 4 个候选方案」原型（点击手机框任一位置可切换控制层显隐，方案 C 的进度条可真实拖动），确认后再实施到 Swift。

方案 A · 底部毛玻璃胶囊推荐

顶栏不做容器，完全沿用现状显示（只用顶部渐变压暗，不套胶囊）。底部换成一颗悬浮毛玻璃胶囊（.ultraThinMaterial/深色等效 + 0.5pt 白描边，与全局页签栏、小说阅读器胶囊同语言），内缩 12pt、圆角 24~29。
顶栏标题按现状裸显示：✕（40pt 圆钮、距屏幕左缘 10pt）+ 书名（去扩展名、13pt semibold、单行、紧随 ✕ 左对齐、超长省略），两者尺寸与位置和现状完全一致、不套任何容器；右侧仅放 ⋯（模式切换 / 亮度菜单），不新增副标题/章节行。
底部主胶囊按语义分组：‹ ›（翻页）｜可拖进度轨 + 白色圆手柄｜页码｜☰（缩略图），胶囊上方一行 10.5pt 细字「第 12/186 页 · 6% · 单页」合并三种进度表达；模式切换（低频）走顶栏 ⋯ 菜单（单页/双页/条漫 + 双页方向 + 亮度），底栏不放设置入口。
优点：观感与全局统一（毛玻璃 + 圆角 + 描边），高频操作全部进主胶囊；模式改动后底栏高度不变；进度轨带手柄即可拖动跳页，复用小说 B+ 的拖动/气泡交互。
缺点：毛玻璃在纯黑漫画页上对比度低，需加 1pt 描边 + 阴影保证可辨识；模式切换收进顶栏菜单、层级略深，改动量小。

方案 B · 沉浸极简内容最大化

控制层降到最轻：顶栏不做容器，完全沿用现状显示（✕ + 书名 + 下一本，只用顶部渐变压暗，不套胶囊），底部不设通栏——只在屏底贴一条 3pt 全宽进度轨（白色填充，滚动/翻页实时跟随），上方并排两个小胶囊「12 / 186」与当前模式名。
呼出时底部居中浮出一个 56pt 胶囊 dock（☰ 缩略图 ｜ ▯▯ 模式切换），两个 44pt 圆钮、无文字标签；再次点击正文即刻隐藏，回到全屏看图。
优点：看图面积最大（控制层总高 ≈ 100pt，去掉浮层后仅剩 3pt 进度轨）；进度轨贴底符合条漫滑动习惯（滚动即见进度）；层次最少的「胶囊 + 贴底轨」组合。
缺点：模式切换只剩图标、无文字（首次使用需猜）；两个小胶囊 + dock 是三个独立浮块，视觉略碎；无翻页箭头，纯靠滑动（iPad 双页模式可能需要保留箭头）。

方案 C · 抽屉工作台功能最全进度条可拖动

底部是一张圆角 26 毛玻璃抽屉（内缩 10pt），三行成组：① 分段控件「单页 / 双页 / 条漫」（选中白底黑字，iOS 分段控件语言，替代三个平铺按钮）；② 可拖动进度条——4pt 轨 + 22pt 白色手柄，拖动中浮出深色气泡实时显示「第 N 页」，松手跳转；③ 操作行「⟲ 方向｜☰ 缩略图｜⤓ 下一本」主按钮（primary 填充，唯一蓝色块）。
顶栏不做容器，沿用现状标题行（✕ / 书名 / 亮度，仅顶部渐变压暗）。
优点：把「设置类」与「操作类」彻底分层，模式切换从底栏一行按钮变成一行分段控件（语义清晰、可扩展更多模式）；拖动进度条 + 气泡是本方案的核心增量；主按钮给「下一本」——翻完后引导阅读。
缺点：抽屉总高 ≈ 150pt，是四个方案里最高的（用「缩略图/亮度」等低频项换来的）；分段控件与「顶部模式菜单」功能重复，需删掉其一避免两处入口。

方案 D · 页码徽章 + 刻度轨长篇友好

页码徽章常驻右上角（半透明黑底胶囊「12/186」，控制层隐藏时也可保留，翻页时轻微淡入切换）；标题完全沿用现状显示方案：✕ + 书名单行左对齐、只用顶部渐变压暗，不套胶囊 / 药丸底；底部是刻度进度轨——3pt 主轨 + 每隔约 10% 一根 2pt 刻度（长篇一眼可见「读到哪一段」），白色手柄可拖；

优点：页码在控制层隐藏时仍可见（解决「沉浸看图时不知道第几页」）；刻度轨让 186 页的长篇有段落感，点击刻度末尾附近可快速跳转；翻页箭头回归，双页/平板场景可点按翻页。
